# ZenCall

## Seamless Real-Time Video Calls

**ZenCall** is a modern web app that enables users to connect through high-quality, real-time video calls. Join a room with a unique ID and start collaborating face-to-face, perfect for meetings, interviews, or casual chats!

**Current Version**: v1.0.0  
🚀 **Live Demo**: [https://zencall-1.onrender.com/]  


---

## ✨ Features

- **Real-Time Video Calls**: High-quality video and audio with minimal latency.
- **Room-Based Access**: Join private calls using unique Room IDs.
- **Multi-User Support**: Multiple participants in a single call.
- **Responsive UI**: Works on desktop and mobile devices.
- **Peer-to-Peer**: Secure and fast connections via WebRTC.

---

## 🛠️ Technologies

- **Frontend**: React, Tailwind CSS
- **Backend**: Node.js, Express
- **Real-Time Communication**: WebRTC, Socket.IO
- **Deployment**: Vercel

---

## 🚀 Getting Started

- Register yourself or go with the demo user option
- Once on the dashboard, click on "video call" button
- Copy the id, and call your friend.
